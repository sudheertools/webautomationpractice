Form Essentials

Forty-four interactive controls covering every HTML form input type, every field state, and every selection pattern you will meet in production apps. Turn on Locator Coach in the top bar, hover any control, and copy its Selenium or Playwright locator.

01Text inputs

Basic text fields

Every native text-like input type. Each has a stable id, name, data-testid and a real <label>.

Beginner
Type: text · Practice: type "Ada" and assert the value.
Use By.ID, "last-name" or getByTestId("last-name").
Type: email — browsers enforce a basic format.
Type: tel — numeric keyboard on mobile.
Type: url — must include a scheme.
Type: search — often has a clear button.
Type: number with min/max/step. Use clear() before typing.
Stepper buttons are siblings of the input — practice reading the value attribute after clicking.
0/120
Type: textarea. The counter has id="bio-count".
🎯 Practice task
  1. Fill first name Ada, last name Lovelace, email ada@example.com.
  2. Assert that #first-name has value Ada using its value attribute.
  3. Type 120 characters into the bio and assert the counter element reads 120.
Show answer (Playwright JS) 
await page.getByTestId("first-name").fill("Ada");
await page.getByTestId("last-name").fill("Lovelace");
await page.getByTestId("user-email").fill("ada@example.com");
await expect(page.getByTestId("first-name")).toHaveValue("Ada");

await page.getByTestId("bio-textarea").fill("a".repeat(120));
await expect(page.locator("#bio-count")).toHaveText("120");

02Field states

Read-only, disabled, hidden & validation

Attributes that change how an element behaves. Automation has to know which ones are interactable and which are only readable.

Intermediate
readonly — you can read value but not type.
disabled — not interactable; assert via toBeDisabled().
Its value is set by JavaScript after load — practice waiting for it.
Filled by JS 2 seconds after page load. Use an explicit wait.
type="hidden" is invisible but readable — great for CSRF-token assertions.
Validation demo
Please enter a valid work email address.
Only letters, numbers and underscore (3–15 chars).
Password must be at least 8 characters.
Postcode must be exactly 6 digits.
🎯 Practice task
  1. Assert #disabled-field is disabled and #readonly-field is enabled but read-only.
  2. Submit the validation form empty and count how many .field.invalid blocks appear (expect 4).
  3. Type an invalid email, click Validate, and assert #val-email-error becomes visible.
Show answer (Selenium Python) 
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

assert driver.find_element(By.ID, "disabled-field").is_enabled() is False
assert driver.find_element(By.ID, "readonly-field").get_attribute("readonly") is not None

driver.find_element(By.ID, "validate-submit").click()
WebDriverWait(driver, 5).until(
    EC.visibility_of_element_located((By.ID, "val-email-error"))
)
invalid = driver.find_elements(By.CSS_SELECTOR, ".field.invalid")
assert len(invalid) == 4

03Checkboxes

Checkbox variants

Single checkboxes, groups, a tri-state (indeterminate) master checkbox and clickable cards.

Beginner
Simple checkboxes
Framework group + count
Selected: 1
Select-all + children

The master checkbox shows the indeterminate state when only some children are checked — a state you cannot set with a plain click.

Checkbox cards (styled inputs)
🎯 Practice task
  1. Check #select-all-modules and assert all 5 .module-cb inputs become checked.
  2. Uncheck #mod-alerts and assert the master checkbox is now indeterminate (not fully checked).
  3. Count checked .framework-cb inputs and compare with the text of #framework-count.
Show answer (Playwright TS) 
await page.getByTestId("select-all-modules").check();
await expect(page.locator(".module-cb")).toHaveCount(5);
for (const cb of await page.locator(".module-cb").all()) {
  await expect(cb).toBeChecked();
}

await page.getByTestId("mod-alerts").uncheck();
// indeterminate is a DOM property, not a checked state
const indeterminate = await page.locator("#select-all-modules")
  .evaluate((el) => el.indeterminate);
expect(indeterminate).toBe(true);

Radio groups

Groups share a name. Selecting one deselects the rest — the classic "click then assert the other is unchecked" exercise.

Beginner

Experience level
Radio cards
🎯 Practice task
  1. Select #gender-male and assert #gender-other is no longer checked.
  2. Assert exactly one radio in input[name="shipping"] is checked, and that its value is express.

WebElement male = driver.findElement(By.id("gender-male"));
male.click();
Assert.assertFalse(driver.findElement(By.id("gender-other")).isSelected());

List<WebElement> checked = driver.findElements(
    By.cssSelector("input[name=\"shipping\"]:checked"));
Assert.assertEquals(checked.size(), 1);
Assert.assertEquals(checked.get(0).getAttribute("value"), "express");

05Native selects

<select> in all its forms

Single select, select with a pre-selected value, grouped options, disabled options and a multi-select list box.

Beginner
Empty first option = "nothing selected yet". Assert value === "" initially.
Has a pre-selected value — assert inr before changing it.
Uses <optgroup> — a good XPath exercise.
Two options are disabled and cannot be selected programmatically by a user.
Type: select multiple. Selected values live in selectedOptions. Selected: (none)
🎯 Practice task
  1. Select India in #country-select by visible text and assert its value is in.
  2. Assert #plan-select has exactly 2 disabled options.
  3. Multi-select xpath, waits and pom in #skills-select and assert the count is 3.
Show answer (Selenium Python) 
from selenium.webdriver.support.ui import Select

country = Select(driver.find_element(By.ID, "country-select"))
country.select_by_visible_text("India")
assert country.first_selected_option.get_attribute("value") == "in"

plan = Select(driver.find_element(By.ID, "plan-select"))
disabled = [o for o in plan.options if not o.is_enabled()]
assert len(disabled) == 2

skills = Select(driver.find_element(By.ID, "skills-select"))
skills.select_by_value("xpath")
skills.select_by_value("waits")
skills.select_by_value("pom")
assert len(skills.all_selected_options) == 3

06Custom dropdown

Non-native dropdown

This is not a <select> — it is a button plus a list of divs. You must click to open it, then click the option. Locators like Select() will fail here, on purpose.

Intermediate
Priority
Open with #priority-btn, then click an item inside #priority-menu.
Sort by
Pre-selected option has aria-checked="true".
ℹ
No selection yet

Pick a priority to see the app react.

🎯 Practice task
  1. Click #priority-btn to open the list, then click the High option.
  2. Assert the button label now reads High and #dropdown-result mentions High.
  3. Assert the menu is closed again (it closes itself after selection).
Show answer (Playwright JS) 
await page.getByTestId("priority-btn").click();
await page.getByTestId("priority-high").click();

await expect(page.getByTestId("priority-btn")).toContainText("High");
await expect(page.locator("#dropdown-result")).toContainText("High");
await expect(page.locator("#priority-menu")).toBeHidden();

07Searchable combobox

Typeahead / autocomplete

Type to filter a list of options rendered as you go. The list is a sibling of the input with role="listbox" — classic autocomplete pattern.

Intermediate
▾
24 options. Filtering is case-insensitive. Clicking an option fills the input and closes the list.
🎯 Practice task
  1. Type pyth into #language-combo-input and wait for the listbox to appear.
  2. Assert every visible option's text contains "Python" (case-insensitive).
  3. Click the first option and assert the input value is Python.
Show answer (Selenium Python) 
box = driver.find_element(By.ID, "language-combo-input")
box.send_keys("pyth")

WebDriverWait(driver, 5).until(
    EC.visibility_of_element_located((By.ID, "language-combo-list"))
)
opts = driver.find_elements(By.CSS_SELECTOR, "#language-combo-list .combo-opt")
assert all("python" in o.text.lower() for o in opts)

opts[0].click()
assert box.get_attribute("value") == "Python"

08Cascading dropdowns

Dependent selects

Each dropdown unlocks the next. The child is disabled until the parent has a value — the most common real-world select pattern.

Intermediate
Waiting for region…
🎯 Practice task
  1. Assert #city-select is disabled before any region is chosen.
  2. Select Asia, wait until #city-select is enabled, then select Mumbai.
  3. Assert #branch-select now has more than one option.
Show answer (Playwright TS) 
await expect(page.getByTestId("city-select")).toBeDisabled();

await page.getByTestId("region-select").selectOption("asia");
await expect(page.getByTestId("city-select")).toBeEnabled();
await page.getByTestId("city-select").selectOption("mumbai");

const branches = await page.getByTestId("branch-select").locator("option").count();
expect(branches).toBeGreaterThan(1);

09Tag / chip input

Tag input with chips

Type a value and press Enter (or comma) to create a chip. Each chip has its own remove button — good for testing repeated dynamic elements.

Intermediate
Selenium Playwright
Press Enter or , to add. Backspace on an empty input removes the last chip. Tags: 2
🎯 Practice task
  1. Type Cypress and press Enter; assert a chip with that text now exists.
  2. Assert the counter #tag-count reads Tags: 3.
  3. Remove the Selenium chip via its button and assert it is gone.
Show answer (Playwright JS) 
await page.getByTestId("tag-input-field").fill("Cypress");
await page.getByTestId("tag-input-field").press("Enter");
await expect(page.getByText("Cypress", { exact: true }).first()).toBeVisible();
await expect(page.locator("#tag-count")).toHaveText("Tags: 3");

await page.getByLabel("Remove Selenium tag").click();
await expect(page.getByTestId("tag-selenium")).toHaveCount(0);
