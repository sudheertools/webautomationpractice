Files & Buttons

File uploads in all three flavours (single, multiple, drag-and-drop), real generated downloads you can assert on, and a gallery of every button pattern — including the ones that lie to your test (loading spinners, disabled states, icon-only targets).

01Single file upload

Native file input

The <input type="file"> is hidden behind a styled label. Automation sets files directly on the input — never on the button.

Beginner
📄

Drop your resume here, or

📄 — —

Target the input itself: #resume-input. Use Playwright's setInputFiles() or Selenium's send_keys(absolute_path).

How to automate uploads

// Playwright
await page.getByTestId("resume-input")
  .setInputFiles("fixtures/resume.pdf");
await expect(page.locator("#resume-filename"))
  .toHaveText("resume.pdf");

# Selenium (Python) — path must be absolute
driver.find_element(By.ID, "resume-input").send_keys(
    os.path.abspath("fixtures/resume.pdf"))
assert driver.find_element(
    By.ID, "resume-filename").text == "resume.pdf"
⚠
Use absolute paths in Selenium

Relative paths silently fail on most drivers. In Playwright, project-relative paths are fine.

🎯 Practice task
  1. Upload a PDF to #resume-input and assert #resume-filename shows its name.
  2. Assert #resume-file is visible and #resume-zone shows a "ready" look.
  3. Click #resume-remove and assert the file row is hidden again.

Show answer (Playwright TS) 
await page.getByTestId("gallery-input").setInputFiles([
  "fixtures/a.png", "fixtures/b.png", "fixtures/c.png"

await expect(page.locator("#gallery-count")).toHaveText("3 files selected");

04Downloads

Generated files you can assert on

These buttons create real blobs client-side. Nothing hits a server, so they work offline — but they still trigger the browser's download machinery.

Intermediate

Text report

report.txt · plain text, deterministic content.

Contains the line RESULT: PASS — assert the downloaded content.

JSON export

data.json · structured, good for API-style assertions.

Has users.length === 5.

CSV rows

users.csv · 1 header + 5 data rows.

Assert the file has 6 lines total.

No download triggered yet.
ℹ
How to assert downloads

Playwright: const dl = await page.waitForEvent("download"); ... await dl.path(). Selenium 4: enable CDP Browser.setDownloadBehavior or use driver.get(downloadUrl) and check the buffer.

🎯 Practice task
  1. Click #dl-text, wait for the download event, and assert the suggested filename is report.txt.
  2. Read the downloaded file and assert it contains RESULT: PASS.
  3. Trigger #dl-json and parse it; assert users.length === 5.
Show answer (Playwright JS) 
const dlPromise = page.waitForEvent("download");
await page.getByTestId("dl-text").click();
const dl = await dlPromise;

expect(dl.suggestedFilename()).toBe("report.txt");
const path = await dl.path();
const body = require("fs").readFileSync(path, "utf8");
expect(body).toContain("RESULT: PASS");

05Button variants

Every kind of click target

Buttons, reset, links that look like buttons, icon-only buttons with only an aria-label, and a split button.

Beginner
Icon-only buttons have no visible text — use getByLabel() or By.cssSelector('[aria-label="…"]').
Split button — two adjacent targets sharing one visual button.
I am an <a> tag Same look, different tag. Affects which locator you should use.
🎯 Practice task
  1. Click #btn-count 3 times and assert #click-count reads 3.
  2. Locate #btn-icon-settings by its accessible name Open settings only (no ID).
  3. Double-click #btn-dbl and assert #click-out mentions "double".
Show answer (Playwright TS) 
const btn = page.getByTestId("btn-count");
await btn.click(); await btn.click(); await btn.click();
await expect(page.locator("#click-count")).toHaveText("3");

await page.getByLabel("Open settings").click();

await page.getByTestId("btn-dbl").dblclick();
await expect(page.locator("#click-out")).toContainText("double");

🎯 Practice task
  1. Click #btn-slow and assert it gains the btn-loading class immediately.
  2. Wait until it is no longer loading, then assert #slow-status says "Saved".
  3. Click #tg-bell and assert aria-pressed flips from true to false.
Show answer (Playwright JS) 
const slow = page.getByTestId("btn-slow");
await slow.click();
await expect(slow).toHaveClass(/btn-loading/);
await expect(slow).not.toHaveClass(/btn-loading/, { timeout: 5000 });
await expect(page.locator("#slow-status")).toHaveText("Saved.");

const bell = page.getByTestId("tg-bell");
await expect(bell).toHaveAttribute("aria-pressed", "true");
await bell.click();
await expect(bell).toHaveAttribute("aria-pressed", "false");
