01Tabs & accordion

Tab set

Proper ARIA tabs: role="tab", aria-selected, aria-controls, roving focus and a deliberately disabled tab.

Intermediate

LocatorLab is a practice site with 110+ interactive elements. Every control carries a stable id, name, data-testid and data-automation-id.

Assert the active tab via aria-selected="true" or the .active class — both are kept in sync.

  • Locator Coach overlay with Selenium & Playwright snippets
  • Every native date/time input type plus custom pickers
  • Sortable, searchable, paginated data table
  • iFrames, nested frames and Shadow DOM

Free. Always. No signup, no backend, no ads.

Self-host it: it is a static folder with zero dependencies.

Accordion

A polling wait that blocks until a condition is true — an element visible, a URL matching, a text present — or a timeout expires. Use it whenever the app is doing work in the background.
Because it is either too short (flaky) or too slow (your suite crawls). A fixed sleep waits the same amount whether the element is ready or never coming.
CSS selectors pierce shadow boundaries in Playwright and Selenium 4's css: >>> piercing combinator. XPath does not cross the boundary — you must pierce step by step.
🎯 Practice task
  1. Click #tab-features and assert #panel-features is visible while #panel-overview is hidden.
  2. Assert #tab-disabled cannot be clicked (it has the disabled attribute).
  3. Expand #acc-2 and assert #acc-panel-2 becomes visible and #acc-1 collapses.
Show answer (Playwright JS) 
await page.getByTestId("tab-features").click();
await expect(page.locator("#panel-features")).toBeVisible();
await expect(page.locator("#panel-overview")).toBeHidden();
await expect(page.getByTestId("tab-disabled")).toBeDisabled();

await page.getByTestId("acc-2").click();
await expect(page.locator("#acc-panel-2")).toBeVisible();
await expect(page.getByTestId("acc-1")).toHaveAttribute("aria-expanded", "false");

05Drag & drop

⚠
HTML5 drag-and-drop is hard to automate

page.dragAndDrop() works in Playwright. Selenium needs click-and-hold with an Actions chain, and even that can fail. That is why this page also ships a keyboard/button fallback — real apps should too.

07Infinite scroll

Intermediate

Loaded 10 items

🎯 Practice task

  2. Assert the item with id="inf-item-25" exists at some point.
Show answer (Playwright JS) 
const list = page.getByTestId("inf-list");
for (let i = 0; i < 5; i++) {
  await list.evaluate((el) => { el.scrollTop = el.scrollHeight; });
  await page.waitForTimeout(300);
}
await expect(page.locator("#inf-list .inf-item")).toHaveCount(40);

08iFrames

Single & nested frames

Both frames load local documents — no network needed. Nested requires two frame switches, which is where most beginners get stuck.

Advanced
Single frame — #single-frame
src="../assets/frames/frame-inner.html"
Nested frame — #nested-host
src="../assets/frames/frame-outer.html" → contains #nested-frame → #frame-input
ℹ
Switching frames

Selenium: driver.switch_to.frame("single-frame") then switch_to.default_content(). Playwright pierces automatically for CSS/XPath in most cases — but you still need frameLocator() when the frame is cross-origin or nested.

🎯 Practice task
  1. Switch into #single-frame, type Hello into #frame-input, click #frame-echo, and assert the message.
  2. Switch back to the default content and assert #frame-title is not found there.
  3. For the nested frame, switch twice and assert #frame-input is reachable.
Show answer (Selenium Python) 
driver.switch_to.frame("single-frame")
inp = driver.find_element(By.ID, "frame-input")
inp.send_keys("Hello")
driver.find_element(By.ID, "frame-echo").click()
assert "Hello" in driver.find_element(By.ID, "frame-msg").text
driver.switch_to.default_content()

# nested: outer then inner
driver.switch_to.frame("nested-host")
driver.switch_to.frame("nested-frame")
assert driver.find_element(By.ID, "frame-input").is_displayed()
driver.switch_to.default_content()

  2. Click #shadow-submit and assert #shadow-msg shows the typed value.

Show answer (Playwright JS) 
// Playwright pierces open shadow roots automatically
await page.getByTestId("shadow-host").locator("#shadow-input").fill("secret");
