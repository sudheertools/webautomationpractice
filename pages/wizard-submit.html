from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
import re

driver.find_element(By.ID, "reg-submit").click()
WebDriverWait(driver, 5).until(
    EC.presence_of_all_elements_located((By.CSS_SELECTOR, ".field.invalid"))
)
assert len(driver.find_elements(By.CSS_SELECTOR, ".field.invalid")) == 7

02Password strength & reveal

Standalone password playground

Same idea, isolated. The strength bar is driven by a computed score exposed as data-score on #pw-meter — an easy assertion target.

Beginner

Score breakdown (0–4)

  • 8+ characters
  • Mix of upper & lower case
  • At least one number
  • At least one symbol
Score: 0 / 4

Start typing…

🎯 Practice task
  1. Type abc and assert #pw-meter has data-score="1".
  2. Type Abcdef1! and assert the score is 4.
  3. Click #pw-toggle and assert #pw-field's type becomes text.
Show answer (Playwright JS) 
const field = page.getByTestId("pw-field");
await field.fill("Abcdef1!");
const score = await page.getByTestId("pw-meter").getAttribute("data-score");
expect(score).toBe("4");

await page.getByTestId("pw-toggle").click();
await expect(field).toHaveAttribute("type", "text");

03OTP input row

Six-digit verification code

Separate boxes with auto-advance and auto-backspace. The composed code lives in a hidden mirror field, so you never have to stitch six values together in your test.

Intermediate
Verification code

Demo code: 482913

🎯 Practice task
  1. Type 482913 digit by digit and assert focus auto-advances to the next box.
  2. Assert the hidden field #otp-value equals 482913.
  3. Click Verify and assert #otp-status reports success.
Show answer (Playwright TS) 
for (let i = 1; i <= 6; i++) {
  await page.getByTestId("otp-" + i).fill(String("482913"[i - 1]));
}
await expect(page.getByTestId("otp-value")).toHaveValue("482913");

await page.getByTestId("otp-verify").click();
await expect(page.locator("#otp-status")).toContainText("verified");
