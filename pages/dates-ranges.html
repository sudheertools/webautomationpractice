Dates & Ranges

Every native date and time input type, a hand-built calendar widget, a date-range picker with duration maths, range sliders and rating controls. The custom calendar is deliberately not a native input — it is the pattern most real apps use.

01Native date & time inputs

All five HTML date/time types

Each stores an ISO-ish string in its value. Automation usually sets the value directly rather than clicking the picker.

Beginner
Type: date → YYYY-MM-DD
Type: time → HH:MM
Type: datetime-local → YYYY-MM-DDTHH:MM
Type: month → YYYY-MM
Type: week → YYYY-Www
Has max — future dates are rejected.
🎯 Practice task
  1. Clear #dob-input, type 2001-05-20 and assert its value.
  2. Set #alarm-input to 06:15 using fill() / sendKeys().
  3. Assert #past-date rejects tomorrow's date (value stays empty or unchanged).
Show answer (Playwright JS) 
await page.getByTestId("dob-input").fill("2001-05-20");
await expect(page.getByTestId("dob-input")).toHaveValue("2001-05-20");

await page.getByTestId("alarm-input").fill("06:15");
await expect(page.getByTestId("alarm-input")).toHaveValue("06:15");

02Custom calendar picker

Hand-built date picker

A real widget: month navigation, day cells with data-day, a "today" outline and a "selected" state. Nothing here is a native input.

Advanced
Month

No date selected.

What to notice

1. Each day is a <button class="cal-day" data-day="2026-03-15"> — the ISO date lives in the attribute, not the text.

2. The selected day carries .selected; today also has .today.

3. The input is readonly — you cannot type into it; you must drive the widget.

4. #cal-prev / #cal-next re-render the grid, so old day locators become stale. Classic "stale element" practice.

⚠
Stale element trap

Never keep a reference to a day button across a month change — re-locate after every navigation.

🎯 Practice task
  1. Click #cal-next twice, then select the 15th of the displayed month.
  2. Assert #trip-date-input equals YYYY-MM-15 for that month.
  3. Click #cal-clear and assert the input is empty and no .selected day exists.
Show answer (Selenium Python) 
driver.find_element(By.ID, "cal-next").click()
driver.find_element(By.ID, "cal-next").click()
month = driver.find_element(By.ID, "cal-label").text  # e.g. "March 2026"

day = driver.find_element(By.CSS_SELECTOR, '#cal-days [data-day$="-15"]')
day.click()

val = driver.find_element(By.ID, "trip-date-input").get_attribute("value")
assert val.endswith("-15")

driver.find_element(By.ID, "cal-clear").click()
assert driver.find_elements(By.CSS_SELECTOR, "#cal-days .selected") == []

03Date range picker

Start & end date with duration

Two inputs plus a calendar. Choosing a start then an end highlights the whole range and the app computes the number of nights.

Advanced
Result
4 nights

2026-04-10 → 2026-04-14

🎯 Practice task
  1. Set check-in 2026-05-01 and check-out 2026-05-04, click Calculate.
  2. Assert #range-nights reads 3 nights.
  3. Set check-out before check-in, click Calculate, and assert an error alert appears.
Show answer (Playwright TS) 
await page.getByTestId("range-start").fill("2026-05-01");
await page.getByTestId("range-end").fill("2026-05-04");
await page.getByTestId("range-calc").click();
await expect(page.locator("#range-nights")).toHaveText("3 nights");

await page.getByTestId("range-end").fill("2026-04-28");
await page.getByTestId("range-calc").click();
await expect(page.locator("#range-out")).toHaveClass(/error/);

05Ratings

Star rating & Likert matrix

The star rating is five visually-hidden radio buttons with real labels — you click the <label>, not the input.

Intermediate
How was the tutorial?

Rating: 3 of 5

Order is rtl — star 5 is the first DOM node.

Locator difficulty
ConceptEasyMediumHard
CSS selectors
XPath axes
Shadow DOM

Radios share name per row — locate them as input[name="lk-css"][value="easy"].

🎯 Practice task
  1. Click the 5-star <label> and assert #star-5 is checked.
  2. Assert #star-out now reads Rating: 5 of 5.
  3. Read every checked radio in #likert-matrix and assert exactly 3 are checked.
Show answer (Selenium Java) 
driver.findElement(By.cssSelector("label[for=\"star-5\"]")).click();
Assert.assertTrue(driver.findElement(By.id("star-5")).isSelected());
Assert.assertEquals(driver.findElement(By.id("star-out")).getText(), "Rating: 5 of 5");

List<WebElement> checked = driver.findElements(
    By.cssSelector("#likert-matrix input[type=\"radio\"]:checked"));
Assert.assertEquals(checked.size(), 3);
