Locator contract

Every interactive element on this site carries four stable hooks plus a real label:

<input
  type="text"
  id="first-name"                 // Selenium: By.id("first-name")
  name="firstName"                // Selenium: By.name("firstName")
  data-testid="first-name"        // Playwright: page.getByTestId("first-name")
  data-automation-id="first-name" // generic / other tools
>
<label for="first-name">First name</label>  // getByLabel / XPath by label

Framework cheat sheet

# Selenium Python
from selenium.webdriver.common.by import By
driver.find_element(By.ID, "first-name")
driver.find_element(By.NAME, "firstName")
driver.find_element(By.CSS_SELECTOR, "[data-testid='first-name']")
driver.find_element(By.XPATH, "//label[text()='First name']/following::input[1]")

 

// Playwright JS
await page.getByTestId("first-name");
await page.getByLabel("First name");
await page.locator("#first-name");
await page.locator('input[name="firstName"]');
