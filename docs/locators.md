## Locator contract

Every interactive element on this site carries:

1. a stable `id` (kebab-case)
2. a stable `name` (camelCase)
3. `data-testid` (same value as `id`)
4. `data-automation-id` (same value as `id`)
5. a real `<label for="…">` or `aria-label`

Prefer `data-testid` in Playwright (`getByTestId`) and `id` in Selenium (`By.id`).
Use `getByLabel()` / `By.xpath("//label[...]/following::input[1]")` when you want to prove the label is wired correctly.
